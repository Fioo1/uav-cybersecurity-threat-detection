# 🚁 Sistema de Gestión de Ciberseguridad Basado en Machine Learning para la Detección de Amenazas en la Operación de UAVs

## 📖 Descripción

La investigación propone un sistema de gestión de ciberseguridad para Vehículos Aéreos No Tripulados (UAVs) que integra mecanismos de protección y técnicas de Machine Learning para detectar amenazas presentes en redes de comunicación UAV.

El sistema combina cifrado, autenticación y detección de intrusos para fortalecer la seguridad de entornos UAV frente a diferentes tipos de ataques.

---

## 🎯 Objetivo

Diseñar e implementar un sistema de gestión de ciberseguridad capaz de detectar amenazas en la operación de UAVs mediante algoritmos de Machine Learning y mecanismos complementarios de protección.

---

## 🔐 Mecanismos de Seguridad

- AES-128 para cifrado de datos
- HMAC-SHA256 para autenticación
- Sistema de Detección de Intrusos (IDS)
- Monitoreo y gestión de eventos de seguridad

---

## 🤖 Modelos Evaluados

- Random Forest
- SVM
- XGBoost
- LightGBM
- CNN + LSTM

---

## 🚨 Amenazas Analizadas

- Blackhole Attack
- Flooding Attack
- Sybil Attack
- Wormhole Attack

---

## 📊 Dataset

UAVIDS-2025

Dataset especializado para la detección de intrusiones en redes UAV con más de 122 mil registros clasificados en múltiples categorías de tráfico.
