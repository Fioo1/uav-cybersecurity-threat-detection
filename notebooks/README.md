# Notebooks

Cuadernos de Google Colab y análisis exploratorios.

## 📂 Experimentos Realizados

Durante el desarrollo de la investigación se realizaron múltiples experimentos para comparar el desempeño de diferentes algoritmos de Machine Learning aplicados a la detección de amenazas en UAVs.

Los notebooks incluidos contienen:

- Preprocesamiento de datos.
- Entrenamiento de modelos.
- Comparación de algoritmos.
- Evaluación mediante métricas de desempeño.
- Análisis de resultados.

Los experimentos consideran modelos como:

- Random Forest
- XGBoost
- LightGBM
- SVM
- CNN
- LSTM
- CNN+LSTM

con el objetivo de identificar la alternativa más adecuada para la detección de intrusiones en redes UAV.
